# RouteXpress
Web-based Delivery Route Planner with Smart Dispatching

## Setup

### Client
1. `cd client`
2. `npm install`
3. `npm run dev`

### Server
1. `cd server`
2. `npm install`
3. Copy `.env.example` to `.env` and set `MONGO_URI`
4. `npm run dev`

## Environment
- `server/.env.example` includes required variables.
